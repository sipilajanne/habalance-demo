HaBalance – digitaalinen läsnäolo-ohjaaja, prototyyppi 11.11.2026

1. Esikatselu: avaa index.html selaimessa. Keskustelu käyttää silloin vain esimerkkivastauksia.
2. Oikea AI-keskustelu: asenna Python 3 ja aseta OPENAI_API_KEY palvelinkoneen ympäristömuuttujaksi. Älä koskaan lisää avainta HTML-tiedostoon.
3. Käynnistä tässä kansiossa: python server.py
4. Avaa samalla koneella http://localhost:8000

Tietopohja (tarkistettu 11.11.2026):
https://habalance.com/
https://habalance.com/valmennus/
https://habalance.com/palvelut/

Tekoälylle on annettu näiltä sivuilta koottu tiivistetty tietopohja. Se ei hae sivuja automaattisesti eikä väitä puhuvansa Hannelen henkilökohtaisella äänellä.

HUOM: tämä on paikallinen kehitysversio. Julkiseen käyttöön tarvitaan vähintään käyttäjien pääsynhallinta, pyyntörajat, kustannusrajat, HTTPS, tietosuojakäytännöt ja turvallisuuden lisätestaus. Keskustelut lähetetään API-palveluntarjoajalle, kun AI on käytössä.
